# 💌 A Question For You

A cute "will you go on a date with me?" page. Both **Yes** and **No** set off a full-screen jumpscare with a scream.

- Made for phones: it goes full screen, vibrates on Android, and plays sound even with the iPhone silent switch on (iOS 16.4+).
- After the tap, a sweet letter types out over a music box for about 8 seconds, then a hard cut to a full-screen photo (`scare.jpg`) and a scream. Swap in any portrait image to change the face.
- The sound is `scream.mp3`: the music box from `tools/make-scream.html` with a recorded scream spliced in at 8.6 s (`LEAD` in `script.js`). The tool page has the ffmpeg command.
- After the scare, a 😂 screen with "Send the link", "watch it again", and a "Made by SK" watermark.

## Host it on GitHub Pages

Repo → **Settings → Pages** → Source: `Deploy from a branch` → `main` / `(root)` → Save.

⚠️ Don't send it to anyone with a heart condition, epilepsy, or anxiety. Keep it fun.
